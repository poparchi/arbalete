# Arbalète

A sidebar for Chrome on macOS, in the spirit of Arc: Favorites as tiles, Spaces with their own
pinned tabs, a command bar, Auto Archive of idle tabs. Everything you arrange stays in Chrome's own
bookmarks and pinned tabs.

This repository holds what you download and read; the source code is not public.

- **The extension** comes from the Chrome Web Store; its page will be linked here once published.
  The sidebar is in Chrome's side panel, on any computer: click Arbalète's icon in the toolbar.
- **Arbalète for Mac**, an optional companion app for macOS only, coming soon: it shows the sidebar
  at the left edge of Chrome's window, outside any page. It will be signed with a Developer ID and
  notarized by Apple, each release with its SHA-256.
- **Privacy policy**: [poparchi.github.io/arbalete/privacy](https://poparchi.github.io/arbalete/privacy/).
  No account, no server, no analytics, no advertising.
- **Questions, bugs, requests**: [issues](https://github.com/poparchi/arbalete/issues).

## En français

Une barre latérale pour Chrome sur macOS, dans l'esprit d'Arc : Favoris en tuiles, Spaces avec
leurs onglets épinglés, barre de commande, archivage automatique des onglets inactifs. Tout ce que
vous rangez reste dans les favoris et les onglets épinglés de Chrome.

- **L'extension** vient du Chrome Web Store ; sa page sera indiquée ici une fois publiée. La barre
  est dans le panneau latéral de Chrome, sur tout ordinateur : cliquez sur l'icône d'Arbalète dans
  la barre d'outils.
- **Arbalète pour Mac**, une app compagnon facultative pour macOS uniquement, bientôt disponible :
  elle affiche la barre au bord gauche de la fenêtre de Chrome, en dehors de toute page. Elle sera
  signée avec un Developer ID et notarisée par Apple, chaque version avec son SHA-256.
- **Politique de confidentialité** : [poparchi.github.io/arbalete/privacy](https://poparchi.github.io/arbalete/privacy/#fr).
- **Questions, défauts, demandes** : [tickets](https://github.com/poparchi/arbalete/issues).
