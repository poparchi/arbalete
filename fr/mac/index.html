Installer Arbalète pour Mac

L'app gratuite qui met la barre d'Arbalète au bord gauche de la fenêtre de Chrome, en dehors de toute page, avec la barre de commande au centre. Pour macOS 13 ou ultérieur, avec l'extension Arbalète dans Google Chrome. Publiée par PopArchi, créateur indépendant en France.

Télécharger Arbalète pour Mac Notes de la dernière version

Le fichier s'appelle Arbalete.dmg et vient de la page des versions du projet, sur GitHub. Si Chrome prévient qu'il est rarement téléchargé, comme toute app récente, conservez-le depuis la liste des téléchargements de Chrome.

macOS va vous faire passer par deux alertes et par ses Réglages Système, puis demander votre mot de passe : c'est prévu, car Apple n'a pas vérifié cette app. Chaque écran est montré ci-dessous, avec ses mots ; comptez quelques minutes.

Arbalète ne vous demandera jamais de désactiver une protection de macOS (Gatekeeper), de modifier « Autoriser les applications téléchargées de » ou de taper une commande dans le Terminal. Si une page ou un message vous le demande, cela ne vient pas d'Arbalète : téléchargez-la seulement depuis cette page.

Pourquoi Apple ne l'a-t-il pas vérifiée ?

Apple ne vérifie (« notarise ») que les apps des développeurs inscrits à son programme payant ; Arbalète pour Mac n'y est pas inscrite. La première fois que vous ouvrez chaque version, macOS la bloque donc jusqu'à ce que vous l'autorisiez vous-même dans ses réglages. L'app est signée par son éditeur, PopArchi, avec son propre certificat (pas un certificat d'Apple), le même à chaque version : ce que vous lui autorisez reste d'une version à l'autre.

Vous pouvez aussi vous en passer : sans l'app, la barre latérale marche déjà dans le panneau latéral de Chrome.

Votre version de macOS : menu Pomme › À propos de ce Mac. Suivez ensuite la partie qui lui correspond.

Sur macOS 15 Sequoia ou 26 Tahoe

  1. Ouvrez Arbalete.dmg, puis Arbalete dans la fenêtre qui s'affiche. macOS ne l'ouvre pas encore :

    Élément « Arbalete » non ouvert
    Apple n’a pas pu confirmer que « Arbalete » ne contenait pas de logiciel malveillant susceptible d’endommager votre Mac ou de porter atteinte à votre vie privée.

    Cliquez sur Terminé. macOS écrit Arbalete sans accent, d'après le nom du fichier : c'est bien Arbalète.

  2. Ouvrez Réglages Système › Confidentialité et sécurité (menu Pomme › Réglages Système…) et descendez jusqu'à Sécurité :

    « Arbalete » a été bloqué pour protéger votre Mac.

    Cliquez sur Ouvrir quand même. Le bouton reste là environ une heure après votre tentative ; passé ce délai, rouvrez l'app depuis l'image disque.

  3. macOS vous avertit une dernière fois : cliquez sur Ouvrir quand même, puis confirmez avec votre mot de passe ou Touch ID. C'est macOS qui le demande : Arbalète ne le voit jamais.

  4. Arbalète demande « Installer Arbalète pour Mac ? » : cliquez sur Installer. Elle se place dans votre dossier Applications et indique à Chrome qu'il peut la lancer ; rien d'autre ne change sur votre Mac.

    De retour dans Chrome, les Réglages d'Arbalète cochent l'étape de l'app d'eux-mêmes. Si vous n'étiez pas passé par leur bouton Obtenir l'app, cliquez-y sur J'ai déjà l'app et acceptez la demande de Chrome, « Communiquer avec les applications natives associées » : c'est cette app.

    Éjectez ensuite l'image disque ; Arbalete.dmg peut aller à la corbeille. Vous n'aurez pas à ouvrir l'app : Chrome la lance.

Sur macOS 13 Ventura ou 14 Sonoma

L'avertissement y est formulé autrement. Le chemin le plus simple est celui que décrit Apple.

  1. Ouvrez Arbalete.dmg. Dans la fenêtre qui s'affiche, cliquez sur Arbalete en maintenant la touche Contrôle (ctrl) enfoncée, puis choisissez Ouvrir. Ne choisissez pas de placer l'app dans la corbeille.

  2. macOS vous avertit : cliquez sur Ouvrir. S'il n'offre pas ce bouton, ouvrez Réglages Système › Confidentialité et sécurité, cliquez sur Ouvrir quand même (proposé pendant environ une heure après votre tentative), puis confirmez.

  3. Arbalète demande « Installer Arbalète pour Mac ? » : cliquez sur Installer, comme à l'étape 4 ci-dessus. Puis éjectez l'image disque.

Ensuite, si vous le souhaitez

Les raccourcis clavier (⌘T, ⌘L, Ctrl+Tab… ; ⌘ est Cmd, ⌃ Ctrl, ⌥ Option, ⇧ Maj) et les aperçus des pages dans le sélecteur s'activent dans les réglages d'Arbalète. macOS demande alors une autorisation, que vous pouvez refuser :

  • Raccourcis clavier : l'Accessibilité. macOS affiche « … aimerait contrôler cet ordinateur à l’aide des fonctionnalités d’accessibilité » et vous renvoie vers Réglages Système › Confidentialité et sécurité, où vous l'autorisez. L'app reçoit alors les touches pressées pendant que Chrome est au premier plan et ne réagit qu'à ses raccourcis, sans rien garder ni envoyer. Dans les champs de mot de passe, Chrome active la saisie sécurisée de macOS : aucune app ne voit ces touches.
  • Aperçus des pages : l'Enregistrement de l'écran. macOS vous demande de l'autoriser, dans Réglages Système › Confidentialité et sécurité ; une fois autorisée, l'app se relance d'elle-même. Elle ne capture que la fenêtre de Chrome au premier plan et garde de petites images en mémoire, jamais sur le disque. Sur macOS 15 et ultérieur, macOS peut vous redemander de temps en temps de confirmer.

Mises à jour et désinstallation

  • Une nouvelle version : l'extension vous prévient, par une flèche sur son icône et dans ses réglages ; celle que vous avez marche en attendant. Téléchargez-la ici et refaites les étapes de votre version de macOS : la nouvelle remplace l'ancienne, et les autorisations données restent. Si Chrome nomme le fichier « Arbalete (1).dmg », c'est le même.
  • Désinstaller : rouvrez Arbalète depuis le dossier Applications et cliquez sur Désinstaller. L'app, et ce qu'elle avait indiqué à Chrome, vont à la corbeille ; vos favoris, onglets et groupes restent dans Chrome. Pour retirer aussi l'extension : clic droit sur son icône dans Chrome, puis Supprimer de Chrome.
Pour les experts : vérifier le fichier et la signature

La page de chaque version donne l'empreinte SHA-256 du fichier. Pour la comparer, dans le Terminal : shasum -a 256 ~/Downloads/Arbalete.dmg (la commande ne fait que lire le fichier).

L'app est signée par le certificat « Arbalete Release Signing », dont l'empreinte SHA-256 est 7d65fe648d3cdd400a7003f3adf3f06cfacea0a46af3ef05f6ca9ec4fbfbe356. codesign -d -r- /Applications/Arbalete.app affiche l'exigence de l'app, qui se termine par certificate leaf = H"b31837e8c047b0d283506bea0417f06658c2e994" : une autre signature n'est pas la nôtre.

Depuis la 0.1.4, chaque version est immuable sur GitHub : ses fichiers ne peuvent plus changer, et GitHub les atteste. Avec l'outil gh : gh release verify-asset v0.1.4 ~/Downloads/Arbalete.dmg -R poparchi/arbalete.

Un souci pendant l'installation ? Écrivez à arbalete@poparchi.com, avec votre version de macOS et le message affiché.
